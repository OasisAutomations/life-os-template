# North Star — the Brain

Direction lives here. Rooms point here; this folder doesn't point at rooms.
IDs are stable: once a goal is G2 it stays G2 — mark it done, never renumber.

| File | Holds |
|---|---|
| `MISSIONS.md` | M# — what life is *for*. Rarely changes. |
| `PROBLEMS.md` | P# — the problems being solved. Every task traces up to one. |
| `GOALS.md` | G# — concrete, dated outcomes that serve a problem/mission. |
| `CHALLENGES.md` | C# — recurring obstacles to watch for. |
| `STATUS.md` | Current phase, current focus, where each goal stands. Updated weekly. |
| `IDEAS.md` | Parked ideas — good, but not now. |

**The chain:** task → G# → P# → M#. If a task can't climb it, question the task.
