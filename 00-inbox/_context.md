## What this room is for
A frictionless dump. Thoughts, ideas, reminders, half-formed plans. Get it out of
{{NAME}}'s head and into a file. Sort later.

## How I (Claude) behave here
- Accept anything. Don't make them categorize while capturing.
- One line per item, prefixed with the date: `- YYYY-MM-DD: ...`
- When asked to "process the inbox," read `inbox.md` and route each item:
  - an action → the right room (or `05-operating-rhythm/today.md` if it's for today)
  - a new goal/mission/problem → offer to add it to `north-star/`
  - a good idea that isn't the current focus → `north-star/IDEAS.md`
  - a how-to or link → `99-reference/`
  Then remove the routed items from `inbox.md` and report where each one went.
